# 발행 (아직 준비 안 됨)

**시작 전 관문: `.claude/skills/지침/SKILL.md` 를 읽고 `지침확인: 한 줄` 을 적은 뒤 진행한다. 이 줄 없이 한 작업은 무효 (지침 5절).**

## 사전 준비 — 코드로 못 한다. 사람이 계정에서 직접 해야 한다

1. 인스타그램 프로 계정 전환
2. 페이스북 페이지 만들고 인스타 계정과 연결
3. Meta 개발자 앱 만들기 (developers.facebook.com)
4. 사진을 올려둘 인터넷 공간 (인스타 API는 인터넷 주소로만 사진을 받는다)
5. 계정명 확정 → 카드 하단 `@계정명` 자리표시자 교체

준비가 끝나면 이 스킬에 자동 업로드를 붙이고, 최종확인 화면의 발행 버튼과 연결한다.

## 준비 전 — 수동 업로드 절차

1. 최종확인에서 발행을 누르면 PNG와 캡션.txt 위치가 안내된다
2. 휴대폰이나 PC 인스타에서 PNG를 순서대로 올린다 (표지가 첫 장)
3. 캡션.txt 내용을 복사해 붙인다 (첫 줄~해시태그~사진 출처까지 전부)
4. 대체텍스트는 인스타 고급 설정 > 대체 텍스트에 붙인다
5. 게시 후 `발행대장.txt`에 한 줄 추가됐는지 확인
