# 대본작성

**시작 전 관문: `.claude/skills/지침/SKILL.md` 를 읽고 `지침확인: 한 줄` 을 적은 뒤 진행한다. 이 줄 없이 한 작업은 무효 (지침 5절).**

**여기서 쓰는 것은 구상연출대본이다 (2026-09-01 확정).** 팩트와 출처는 여기서 확정하지만, 문장·강조 단어·글 배치는 가안이다. 이미지가 먼저라는 원칙대로, 카드제작에서 실제 사진을 확보한 뒤 사진에 맞춰 문장을 다듬어 확정한다. 글을 먼저 잠그고 사진을 억지로 끼우는 순서 금지.

## 1. 입력

- `주제풀.txt`에서 주제 1건 (2차 점수 높은 것부터)
- **주제풀이 비어 있으면 여기서 멈추고 주제발굴부터 돌린다. AI 머리에서 주제를 지어내는 것 금지** — 머리에서 나온 주제는 뻔한 것뿐이다 (2026-09-01 실제 사고: "야식 먹으면 안 좋다"류)
- 그 주제의 출처 링크를 읽고 팩트를 확인한 뒤에 쓴다
- **팩트체크가 필요한 문장은 무조건 확인한다. 확인 안 되는 문장은 못 쓰고, 그 문장 없이는 대본이 안 되면 주제를 폐기한다.**
- 블로그·커뮤니티는 단서로만. 출처로 인정하는 건 공식 기관·언론뿐

## 2. 구조 (2026-09-01 확정 — 짧게 만든다)

- 요즘 한국 카드뉴스는 길게 안 만든다. **기본 2~3장으로 끝낸다.** 4~6장짜리는 열 건 중 한두 건만 (내용이 진짜 많을 때만)
- 기본 3장 틀: **표지 → 본문 → 마지막 정보 장**
- **한국식은 마무리가 없다 (2026-09-01 확정). 마지막 정보를 보여주면 그냥 끝.** "저장해두세요"·"댓글 남겨주세요"·"팔로우" 같은 맺음 인사는 해외 스타일이라 안 쓴다. 마무리 전용 장은 당연히 금지
- 댓글 유도가 필요하면 카드가 아니라 **캡션에서** 한다
- **넘김 후킹 (유머·어그로 주제용, 방식 중 하나일 뿐):** 랭킹이면 5~2위 보여주고 1위를 마지막 장에 까기 + 앞 장 끝에 궁금증 한 줄("그리고 1위는 절반이 틀립니다 →"). 이렇게 끝나는 건 정보로 끝나는 거라 맺음 금지에 안 걸린다. 다른 후킹 방식도 얼마든지 가능 — 주제 보고 고른다. 정보형은 후킹 없이 그냥 끝나도 됨
- 장수는 주제가 정한다. 억지로 늘리지 않는다

## 2-1. 패턴 4축 조합 규칙 (2026-09-04 신설 — 반복 방지 + 창작 강제)

패턴은 4축의 조합이다. 축별 선택지 목록은 새로 안 만들고 이미 있는 목록을 그대로 쓴다:

| 축 | 선택지 목록이 있는 곳 |
|---|---|
| ① 형식 | 카드제작 스킬 4-3절 스타일 도감 (스타일 번호로 적음) |
| ② 표지 훅 | 이 스킬 3-0의 제목 공식 (공식 이름으로 적음) |
| ③ 어투 | 이 스킬 3-1의 말투 목록: 존댓말 구어체 / 단답체 / 혼잣말체 / 호들갑체 |
| ④ 전개 구조 | 랭킹(5위→1위) / 유형나열 / 반전상식(통념→진실) / 타임라인(사건 경과) / 압축3장 (실물에서 나온 것만. 계속 추가) |

**절차 — 대본 쓰기 전에:**
1. `발행대장.txt` 최근 10건의 조합 표기를 읽고 결과를 한 줄로 적는다.
   예) "조합확인: 최근 10건에 혼잣말체 4번·유형나열 3번 → 이번엔 존댓말+반전상식 쪽"
   **이 줄 없이 쓴 대본은 무효** (주제발굴의 비율 게이트와 같은 방식)
2. **금지:** 최근 10건과 4축이 전부 같은 조합은 탈락. 3축이 같으면 그 발행물의 대본.txt를 실제로 열어 훅·어투까지 대조하고, 느낌이 겹치면 탈락
3. **강제(창작 지점):** 매번 최소 한 축은 최근 10건에 안 나온 선택지를 쓴다. 목록의 선택지가 다 소진됐으면 **그 축의 새 선택지를 발명해서 위 목록(또는 3-0·4-3)에 추가한 뒤** 쓴다. 발명은 축 단위로만 — "완전히 새로운 카드" 같은 통짜 창작 금지
4. 고른 조합은 대본.txt 머리줄에 4축 다 적는다 (예: "스타일11 / ?!훅 / 단답체 / 유형나열" — 스타일 번호는 카드제작 4-3절 도감의 8~13 중에서)

## 3-0. 표지 제목 공식 (12종 중 소재에 맞는 것 하나를 고른다)

준다("○만원 준다") / 시점("9월부터·이제는·드디어") / 호명·필독("운전하는 사람 필독") /
N가지("몰랐던 4가지") / 모르면 손해 / ~한 이유(답은 본문에) / 따옴표 한마디 /
질문→명령("이사했다면? 받아가세요") / 모음.zip / VS 논쟁 / ?!(믿기 어려운 사실) / 1인칭 혼잣말("나 ○○인데") /
**저장형 형식어**(~별 세분화 · 총정리 · ~하는 법 · 꿀팁 모음 — 벤치마킹 계정의 주력 공식)

- **완독 장치**: 표지에서 답을 다 주지 않는다. 답은 본문에서
- 돈 소재는 표지에 금액 숫자를 반드시 넣는다

## 3-1. 본문 글 규칙 (계정 10곳 분석으로 확정)

- **제목은 어그로여도 된다. 그러나 2장부터는 무조건 정보다 (2026-09-01 사용자 확정).**
  - 표지는 클릭을 만드는 장치라 과장·드립·셀럽 얼굴 다 허용. 대신 **2장을 넘긴 순간부터는 읽은 사람이 "이건 몰랐네" 할 알맹이가 반드시 있어야 한다**
  - **모두가 아는 정보는 정보가 아니다.** 민생지원금처럼 온 국민이 아는 건 아무리 정리해도 탈락. 검증 질문: "내 친구 10명 중 몇 명이 이미 알까?" 절반 이상 알 것 같으면 버린다
  - 어그로 표지 + 알맹이 없는 본문 = 낚시. 팔로우 끊기는 지름길이라 최악
  - 재미·테스트 글도 같다. 정보 대신 "처음 보는 관점·결과"가 알맹이 역할을 해야 한다
- **제목 예시 목록은 말투 교본이 아니라 소재·장르의 기준이다 (2026-09-01 사용자 확정).** 예시가 재미·연예·테스트·습관·모음이면 만드는 내용도 그 장르다. 관공서 안내문 같은 소재를 예시 말투로 포장하는 건 탈락
- **원인이 아니라 해결을 쓴다.** "왜 그런가"는 읽고 끝, "어떻게 하나"라야 저장한다
- **정보 밀도가 본체다 (2026-09-01 사용자 확정).** 팁 하나당 4~6줄, 원리(왜 되는지) + 구체 수치·레시피(몇 도, 몇 분, 뭘 넣는지)까지. 한 줄짜리 요약 불릿만 나열하면 탈락
- 첫 줄은 숫자·핵심부터. 설명은 뒤로
- 한 장 3~5줄, 덩어리 최대 3개, 색 강조는 장당 단어 하나 (꿀팁형은 위 밀도 규칙이 우선)
- 말투는 분위기에 맞게 자유 (2026-09-01 사용자 확정). 존댓말 구어체("돼요")·단답체("~하기 쉬움")·혼잣말체("~온 듯..") 다 됨 — 참고자료 실물들이 실제로 그렇다. 기준은 소재 분위기와 미감. **단 한 세트 안에서는 말투 하나로 통일**
- 숫자는 내 지갑 기준으로 환산해준다 ("30만원 = 휘발유 1,200리터")
- 설명 대신 실물을 보여준다 (실제 입력 예시, 실제 계산 단계 "정가 6만 → 내가 낼 돈 3만")
- 미확정·변수는 숨기지 않고 정직하게 표기 ("국회 통과 전 미확정")

## 3-3. 맺음 관련

- 카드에는 맺음 인사 없음 (2번 구조 규칙 참고). 댓글 유도·저장 유도는 **캡션에서만**
- 국룰 제안형(기준을 창작으로 제시)은 반드시 "※ 국룰 제안, 공식 아님" 표기

## 3. 문장 규칙

- **대시(— · ㅡ) 절대 사용금지.** 문장 연결이 필요하면 그냥 문장을 끊는다 (2026-09-01 사용자 확정)
- 한 장에 메시지 하나
- 표지는 후킹 필수. 단 **사기성 금지** — 안 지킬 약속, 과장, 낚시 제목 안 됨. 본문이 표지의 약속을 지켜야 한다
- 글자수 구간은 아직 강제하지 않는다. 문장마다 글자수만 기록해둔다 (대본 20개 쌓이면 실측해서 규칙 확정 예정)

## 4. 자동 승인 기준 — 전부 통과해야 승인

1. 장수 3~5 (심리테스트 3~8)
2. 팩트 문장마다 출처가 있다 (심리테스트 창작 문장은 제외)
3. 메시지 두 개가 섞인 장이 없다
4. 표지에 후킹이 있고, 사기성이 없다
5. 같은 말을 반복하는 장이 없다

## 5. 미달이면

- 다시 쓴다. **최대 3번.**
- 3번 다 미달이면 그 주제는 건너뛰고 `오류기록.txt`에 날짜 + 사유 한 줄. 다음 주제로 넘어간다.

## 6. 출력

1. `제작/날짜_제목/` 폴더를 만든다. 예) `제작/2026-09-01_에너지바우처/`
2. 그 안에 `대본.txt` 저장. 한 장당 한 줄:

```
장번호 | 유형(표지/본문/강조/마무리) | 문장 | 글자수
```

3. 맨 밑에 출처 링크를 그대로 옮겨 적는다 (캡션·확인 단계에서 쓴다)
4. 사용한 주제는 `주제풀.txt`에서 지운다 (제작 폴더로 넘어갔으니 후보 아님)
5. 다음 단계: 스킬 `카드제작`으로 넘긴다
