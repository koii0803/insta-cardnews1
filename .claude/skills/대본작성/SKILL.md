# 대본작성

전부 자동이다. 사람은 스킬 5(최종확인)에서만 본다.

## 1. 입력

- `주제풀.txt`에서 주제 1건 (2차 점수 높은 것부터)
- 그 주제의 출처 링크를 읽고 팩트를 확인한 뒤에 쓴다
- **팩트체크가 필요한 문장은 무조건 확인한다. 확인 안 되는 문장은 못 쓰고, 그 문장 없이는 대본이 안 되면 주제를 폐기한다.**
- 블로그·커뮤니티는 단서로만. 출처로 인정하는 건 공식 기관·언론뿐

## 2. 구조 (2026-09-01 확정 — 짧게 만든다)

- 요즘 한국 카드뉴스는 길게 안 만든다. **기본 2~3장으로 끝낸다.** 4~6장짜리는 열 건 중 한두 건만 (내용이 진짜 많을 때만)
- 기본 3장 틀: **표지 → 본문 → 마지막 정보 장**
- **한국식은 마무리가 없다 (2026-09-01 확정). 마지막 정보를 보여주면 그냥 끝.** "저장해두세요"·"댓글 남겨주세요"·"팔로우" 같은 맺음 인사는 해외 스타일이라 안 쓴다. 마무리 전용 장은 당연히 금지
- 댓글 유도가 필요하면 카드가 아니라 **캡션에서** 한다
- **넘김 후킹 (유머·어그로 주제용, 방식 중 하나일 뿐):** 랭킹이면 5~2위 보여주고 1위를 마지막 장에 까기 + 앞 장 끝에 궁금증 한 줄("그리고 1위는 절반이 틀립니다 →"). 이렇게 끝나는 건 정보로 끝나는 거라 맺음 금지에 안 걸린다. 다른 후킹 방식도 얼마든지 가능 — 주제 보고 고른다. 정보형은 후킹 없이 그냥 끝나도 됨
- 장수는 주제가 정한다. 억지로 늘리지 않는다

## 3-0. 표지 제목 공식 (12종 중 소재에 맞는 것 하나를 고른다)

준다("○만원 준다") / 시점("9월부터·이제는·드디어") / 호명·필독("운전하는 사람 필독") /
N가지("몰랐던 4가지") / 모르면 손해 / ~한 이유(답은 본문에) / 따옴표 한마디 /
질문→명령("이사했다면? 받아가세요") / 모음.zip / VS 논쟁 / ?!(믿기 어려운 사실) / 1인칭 혼잣말("나 ○○인데") /
**저장형 형식어**(~별 세분화 · 총정리 · ~하는 법 · 꿀팁 모음 — 벤치마킹 계정의 주력 공식)

- **완독 장치**: 표지에서 답을 다 주지 않는다. 답은 본문에서
- 돈 소재는 표지에 금액 숫자를 반드시 넣는다

## 3-0-1. 제목 감각 (2026-09-01 확정 — 규칙보다 예시가 본체)

제목은 설명문이 아니라 **친구가 카톡으로 보내는 한마디**다. 판정 질문: "친구가 이 문장을 카톡으로 보낼 법한가?" 설명문이면 탈락.

**좋은 제목 실물 (사용자 확인본 — 이 결을 따라한다):**
- OTT 기강 잡으러 온 조선판 장이수? ㄷㄷ
- 남성판 호텔델루나 드디어 나온대!!
- 보고나니 국뽕도 채우고 맥주도 땡기는 그 조합
- GS25에서만 판다는 추성훈 아조씨
- 유세윤식 재결합은 무조건 개그
- 메가커피가 스벅 기강 잡으러 왔다는 신메뉴 ㄷㄷ
- 군대에서 난리 났다는 그 라면 조합, 사회에서도 됨
- 다이소 직원들만 조용히 쟁여둔다는 물건 5개
- 편의점 알바가 절대 안 사 먹는 도시락 (이유 소름)
- 카리나가 입자마자 또 품절난 그 원피스
- 여자들이 질투하는 여자 9
- 제주도 즐기기 좋은 종류별 여행지 정리
- 오늘의 OOTD를 키링으로! 픽셀 키링 만드는 법
- '이거' 끊으면 건강해집니다!
- 요새 MZ들은 이렇게 투표인증 한데
- 20대와는 확연히 다른 30대 연애 특
- 10개만 시행하면 살이 빠진다구요?
- 6시간 이상 잠을 자야하는 이유
- 연예인 내돈내산 품절템 모음.ZIP

**제목 위 한 줄(말풍선)도 같이 쓴다:** "@@아니 그럼 뭘 먹어요..", "@@저장하고 일단 해볼까..?", "@@은 귀여워~! 나도 해볼까?" 같은 혼잣말·리액션 한 줄을 제목 위에 얹는 것이 이 판의 국룰.

**셀럽 표지 3종 세트 예시 (사용자 승인 2026-09-01) — 사진 장면 + 말풍선 + 제목(【】=색 강조)을 한 묶음으로 짠다. 인물은 주제와 무관, 장면만 매칭:**
- 누워서 셀카 / @@아니 잤는데 왜 더 피곤해요.. / 주말에 몰아자면 【더 피곤해지는】 이유
- 빵 물고 먹방샷 / @@그럼 뭐 어떡해요 배고픈데.. / 야식 먹고 바로 자면 【생기는 일】 3가지
- 공항 캐리어 / @@저장하고 다음 휴가 때 써먹자.. / 비행기표 제일 싸게 사는 타이밍, 【이날임】
- 운동복 거울셀카 / @@저도 오늘부터 1일 해볼까요.. / 헬스 첫날 【뻘쭘하지 않는 법】.ZIP
- 환하게 웃는 셀카 / @@분명 같은 말인데 느낌이 다르네..? / 인상 좋다는 소리 듣는 사람들 【말버릇 5】
- 럭셔리 일상샷 / @@쟤들은 대체 어떻게 모으는 거야.. / 20대에 1천만원 모으는 사람 【공통점 4】

참고: 전체 30건 중 연예인 글은 4~5건 수준. 대신 **연예인 건은 유입이 제일 크므로 제일 공들여 만든다.**

**쓰는 기술:** 아는 것에 빗대기(조선판 장이수) / 목격담 말투(~판다는, ~났다는) / 호들갑(!!, ㄷㄷ, 드디어) / 내부자 프레임(직원들만, 알바가)

**과정:** 주제 하나당 말투 다르게 후보 5개(드립형/호들갑형/목격담형/궁금증형/저장형) 지어보고 제일 카톡스러운 걸 고른다.

**금지:** "~비교", "~정리", "~하는 법" 같은 보고서 제목은 저장형 정보 글에만 허용.

사용자가 "이 제목 좋다"고 한 것은 위 예시 목록에 계속 추가한다.

## 3-1. 본문 글 규칙 (계정 10곳 분석으로 확정)

- 첫 줄은 숫자·핵심부터. 설명은 뒤로
- 한 장 3~5줄, 덩어리 최대 3개, 색 강조는 장당 단어 하나
- 말투는 존댓말 구어체 ("돌려받아요", "돼요")
- 숫자는 내 지갑 기준으로 환산해준다 ("30만원 = 휘발유 1,200리터")
- 설명 대신 실물을 보여준다 (실제 입력 예시, 실제 계산 단계 "정가 6만 → 내가 낼 돈 3만")
- 미확정·변수는 숨기지 않고 정직하게 표기 ("국회 통과 전 미확정")

## 3-2. 카드 부품 (본문 모양 고를 때 이 중에서)

기존: 본문 / 본문표 / 목록 / 강조
추가 예정 4종: **예시 상자**(터미널풍 실물 예시) / **좌우 비교**(옛것→새것 화살표) / **체크리스트**(✓ 조건 나열) / **이모지 소제목**(번호 대신 💪🔍💰)
※ 추가 4종은 카드생성기(작업파일/카드생성.py)에 아직 코드가 없다. 처음 쓸 때 만들어야 함

## 3-3. 맺음 관련

- 카드에는 맺음 인사 없음 (2번 구조 규칙 참고). 댓글 유도·저장 유도는 **캡션에서만**
- 국룰 제안형(기준을 창작으로 제시)은 반드시 "※ 국룰 제안, 공식 아님" 표기

## 3. 문장 규칙

- 한 장에 메시지 하나
- 표지는 후킹 필수. 단 **사기성 금지** — 안 지킬 약속, 과장, 낚시 제목 안 됨. 본문이 표지의 약속을 지켜야 한다
- 글자수 구간은 아직 강제하지 않는다. 문장마다 글자수만 기록해둔다 (대본 20개 쌓이면 실측해서 규칙 확정 예정)

## 4. 자동 승인 기준 — 전부 통과해야 승인

1. 장수 3~5 (심리테스트 3~8)
2. 팩트 문장마다 출처가 있다 (심리테스트 창작 문장은 제외)
3. 메시지 두 개가 섞인 장이 없다
4. 표지에 후킹이 있고, 사기성이 없다
5. 같은 말을 반복하는 장이 없다

## 5. 미달이면

- 다시 쓴다. **최대 3번.**
- 3번 다 미달이면 그 주제는 건너뛰고 `오류기록.txt`에 날짜 + 사유 한 줄. 다음 주제로 넘어간다.

## 6. 출력

1. `제작/날짜_제목/` 폴더를 만든다. 예) `제작/2026-09-01_에너지바우처/`
2. 그 안에 `대본.txt` 저장. 한 장당 한 줄:

```
장번호 | 유형(표지/본문/강조/마무리) | 문장 | 글자수
```

3. 맨 밑에 출처 링크를 그대로 옮겨 적는다 (캡션·확인 단계에서 쓴다)
4. 사용한 주제는 `주제풀.txt`에서 지운다 (제작 폴더로 넘어갔으니 후보 아님)
