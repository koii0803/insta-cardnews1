# 최종확인 — 사람이 보는 유일한 곳

**시작 전 관문: `.claude/skills/지침/SKILL.md` 를 읽고 `지침확인: 한 줄` 을 적은 뒤 진행한다. 이 줄 없이 한 작업은 무효 (지침 5절).**

## 1. 확인 화면

- `제작/날짜_제목/` 안에 확인용 HTML 한 장을 만든다
- 더블클릭 한 번으로 열리게 실행 파일(.bat)을 같이 만든다 (파이썬 서버가 뒤에서 같이 뜬다)
- 한 화면에 보여줄 것
  - 카드 전부 (실제 모양 그대로)
  - 캡션 + 해시태그 (캡션.txt 그대로)
  - 혜택 주제면 마감일 크게

## 2. 체크 항목 (화면 위에 체크리스트로 표시)

- 오탈자
- 글자 잘림
- 사진 어울림
- 마감일 (혜택)

## 3. 버튼 두 개

- **폐기** → 폴더를 `제작/폐기/`로 옮긴다. 바로 지우지 않는다 (실수 방지. 진짜 삭제는 사람이 가끔 폐기 폴더를 비움)
- **발행** →
  1. 오늘이 마감일을 지났으면 경고를 먼저 띄운다 (혜택)
  2. 크롬으로 카드를 1080x1350 PNG로 뽑는다. 실패하면 2번까지 재시도, 그래도 안 되면 멈추고 `오류기록.txt`에 한 줄
  3. 지금(발행 스킬 준비 전): PNG + 캡션 위치를 알려주고 수동 업로드 순서 안내
  4. 나중(발행 스킬 준비 후): 인스타 자동 업로드까지

## 4. 발행 후

`발행대장.txt`에 한 줄 추가: `날짜 [카테고리] 제목`
