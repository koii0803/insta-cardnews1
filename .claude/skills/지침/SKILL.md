# 지침 — CLAUDE.md, 이것은 사용자의 지침이다. 무조건 해라.

**이 파일은 참조칸이다. 참조는 읽지 않으면 못 넘어간다:**
- 이 파일을 읽은 뒤, 작업을 시작하기 전에 `지침확인: (오늘 작업에 적용할 핵심 한 줄)` 을 먼저 적는다
- 이 줄 없이 진행한 작업은 전부 무효다. 돌아가서 읽고 다시 한다
- 요약 복붙 금지 — 읽어야만 쓸 수 있는, 오늘 주제에 붙는 구체적인 한 줄이어야 한다
  예) "지침확인: 오늘은 색 로테이션 위반 조심 — 직전 2세트가 노랑·하늘 썼음"

## 1. 절대규칙

1. **코드는 무조건 승인을 받는다.** 코드는 자물쇠로 잠가둔 것으로 취급한다.
   승인 없이 파일을 만들거나 고치거나 지우지 않는다.
2. **거짓말을 하지 않는다. 사용자를 희롱하지 않는다.**
3. **거짓말하지 말라고 했다고 해서 말을 돌려서 회피하지 않는다.**
   모르면 모른다고 하고, 못 하면 못 한다고 한다. 되는 척하지 않는다.

이 세 가지는 다른 어떤 규칙보다 우선한다.

## 2. 말하고 쓰는 법

- "만들어" / "ㄱㄱ" 없으면 아무것도 만들지 마라. 논의만 한다.
- **질문은 언제든지 마음껏 한다.** 애매하면 추측으로 진행하지 말고 물어본다. 질문이 많은 건 잘못이 아니다.
- 무조건 간단하게 쓴다.
- 사용자는 코드를 모른다. 알아듣기 쉽게 설명한다.
- 코드는 추가만 하지 말고 겹치는 것·빈틈을 찾아서 지운다.

## 3. 방 시작 루틴 (순서대로)

1. **서치(발굴·웹검색) 전에 반드시** 스타일 도감 이미지(`참고자료/스타일도감/`, 색인은 카드제작 스킬 4-3절) 먼저 보기 — 감각 장전. 이게 교본.
   - **"참고"의 뜻 (2026-09-04 사용자 확정): 복사가 아니다. 느낌만 가져간다.** 레이아웃·문구·색을 그대로 베끼면 탈락. 전부 다 볼 필요 없다. 느낌 파악이 됐으면 그만 보고 웹서칭으로 넘어간다.
   - **예전에 만든 작업물(제작/ 폴더의 과거 세트, 예전 방 결과물)은 교본으로 보지 않는다 (2026-09-04 사용자 확정 — 수준 미달). 감각은 도감에서만 가져온다.**
   - **느낌만 가져가되, 한 세트 안에서는 통일감이 있어야 한다 (2026-09-04 사용자 확정).** 글씨체·강조색·말투가 전 장에서 한 몸이어야 한다. 셀프 체크 방법은 → 카드제작 스킬 4-3절 "통일성 셀프 체크"를 보고 해라.
   본 다음엔 발행 비율 확인(주제발굴 스킬의 비율 게이트)까지 하고 서치 시작
2. 상태 확인 — `발행대장.txt` · `주제풀.txt` · `제작/` 폴더 이름
3. 그날 할 작업의 스킬 읽기

## 4. 작업 방식·파이프라인

파이프라인: **주제발굴 → 대본작성 → 카드제작 → 캡션작성 → 최종확인 → 발행(수동)**

| 스킬 | 하는 일 | 사람 개입 |
|---|---|---|
| 주제발굴 | 후보 수집 + 3단계 검증 → 주제풀.txt | 없음 |
| 대본작성 | 대본 3~8장 (심리테스트 3~12장) | 없음 |
| 카드제작 | 템플릿 + 사진 → HTML 카드 | 없음 |
| 캡션작성 | 캡션.txt | 없음 |
| 최종확인 | 한 화면 + 폐기/발행 버튼 | **유일한 확인 지점** |
| 발행 | 인스타 업로드 (준비 안 됨, 수동 절차 있음) | 계정 준비는 사람 |

- **전부 자동이다. 발굴~캡션까지 사람 승인 없음. 사람은 최종확인에서 한 번만 본다.**
- 스킬 6개에는 실행 절차만 있다. 공통 규칙의 본체는 이 지침 파일이다.
- 스킬 내용과 이 파일이 다르면 이 파일이 우선. 다만 겹치는 규칙을 두 군데 적지 않는다.
- **참고자료/의 실물 스크린샷이 곧 교본이다.** 작업 전에 훑어보고, 글로 된 규칙과 실물 느낌이 부딪히면 실물을 따른다. 감각은 글이 아니라 이미지로 배운다.

## 5. 참조 강제 규칙 (2026-09-02 신설)

스킬·지침 안의 "→ 어디를 봐라" 참조는 장식이 아니라 **관문**이다.

1. 참조가 걸려 있으면 그 파일·절을 실제로 따라가 읽는다
2. 읽고 뭘 가져왔는지 **한 줄 기록**을 남긴다. 예) "제목예시 확인: 내부자 프레임 결로 서치 방향 잡음"
3. **기록 없이 넘어간 단계는 무효다.** (주제발굴의 비율 게이트·막히면 루프와 같은 방식)
4. 참조를 적을 때는 "카드제작 스킬 4-3절" 처럼 **파일 + 절 번호**로 정확히 찍는다. "어딘가에 있음" 식 금지

## 6. 파일·폴더

```
클로드쓰레드자동화/
  CLAUDE.md      문지기. 규칙 본체는 이 지침 스킬
  발행대장.txt   발행한 것. 날짜 + 카테고리 + 제목 한 줄
  주제풀.txt     후보만 (탈락 안 적음). 한 건당 3줄 (제목/근거/출처)
  오류기록.txt   오류·특이사항. 날짜 + 한 줄
  .claude/skills/  지침(본체) + 실행 스킬 6개
  참고자료/      벤치마킹 스크린샷 모음 (작업 전 AI가 봄)
  제작/          날짜_제목 폴더. 폐기는 제작/폐기/ 로 이동
  작업파일/      스크립트(카드생성.py), 폰트, pixabay 키
```
