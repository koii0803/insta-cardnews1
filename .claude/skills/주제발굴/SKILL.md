# 주제발굴

**시작 전 관문: `.claude/skills/지침/SKILL.md` 를 읽고 `지침확인: 한 줄` 을 적은 뒤 진행한다. 이 줄 없이 한 작업은 무효 (지침 5절).**

## 노션 소재 입구 (2026-09-06 신설)

사용자가 소재를 직접 주는 경로. 이 절만 있으면 한 줄 명령으로 움직일 수 있게 다 적어놨다 — **여기 없는 걸 찾겠다고 노션을 검색하거나 다른 파일을 뒤지지 마라 (토큰 낭비 금지).**

### 입-1. 명령 두 가지

| 명령 | 하는 일 |
|---|---|
| "소재 정리해" / "붙여넣기 정리해" 계열 | 아래 **입-3 (정리)** 만 하고 보고 |
| "노션가서 만들어" 계열 | 입-3 (인박스에 내용 있으면) → **입-4 (제작)** 까지 |

둘 다 이 스킬의 발굴처 서치는 안 한다.
- **정리만** 하는 명령이면 시작 루틴 경량판: 지침확인 + 상태 확인(발행대장·주제풀·오늘자 오류기록)만 하고 바로 정리. **스타일도감·비율 게이트 생략** (제작 안 하니까 — 토큰 절약, 2026-09-06)
- **제작까지** 가는 명령이면 방 시작 루틴 전부 그대로

- DB 칸 7개: `소재`(제목) · `카테고리`(정보/연예인/순수재미/제철·시의성/심리테스트) · `순위`(급함/D-7/상시) · `상태`(대기/사용/폐기) · `신호`(왜 화제인지 한 줄) · `출처`(어디서 온 소재인지) · `검증메모`(판정 한 줄) · `사용자 제공`(O/X)
- **소재기록 DB는 사용자 열람 전용 — 절대 건드리지 않는다.** 허브 페이지도 수정하지 않는다

### 입-3. 정리 (인박스 → 후보 DB)

붙여넣기는 사람, 정리는 AI다.

1. 인박스를 열어 본문을 읽는다 (상단 안내 콜아웃은 페이지 설명이니 그대로 둔다)
2. 항목마다 즉석 판정한다. **이 단계에서는 웹검색을 하지 않는다** — 상식으로 명백한 것만 거르고, 애매하면 일단 살린다 (검색 검증은 제작 단계 몫):
   - 버림: 다 아는 지원금·혜택(민생지원금·근로장려금급으로 뉴스 도배된 것), 의료·건강 **조언**(진단·치료·식이 효능), 시즌 지난 것(철 지난 명절·여름 이슈), 비방·정치·재난, 발행대장/후보 DB/**오늘자 오류기록.txt**에 이미 있는 것
   - 살림: 나머지 전부. 숨은 혜택·신박 각도는 지원금이라도 살린다. **재테크·세금도 조언(사라·팔아라)만 버리고 제도·숫자 팩트는 살린다** (1차 게이트 리스크 항목 참조)
3. 살릴 것마다 후보 DB에 행 생성. 칸 채우는 법:
   - `소재`: 원문 제목 그대로 (가공은 제작 단계에서)
   - `카테고리`: 5개 중 택1 / `상태`: 대기 / `사용자 제공`: O
   - `순위`: 유통기한으로 판정 — **급함**(방금 화제, 며칠 내 죽음) / **D-7**(날짜 박힌 것: 행사·마감·시행일) / **상시**(언제든)
   - `신호`: 왜 화제인지 한 줄 / `출처`: 원문 어디서 왔는지 / `검증메모`: "정리 통과, 검증은 제작 시"
   - 행 본문에 원문을 그대로 보존한다
4. 다 옮겼으면 인박스에서 옮긴 내용을 지운다 (안내 콜아웃과 구분선 위는 남김). **옮기기 전에 지우면 원문이 날아간다 — 순서 엄수**
5. 보고: 채택 n건(카테고리별) / 버림 n건(사유별 묶어서 한 줄씩)

### 입-4. 제작 (후보 DB → 1세트)

1. `상태=대기`를 `급함 → D-7 → 상시` 순으로 집는다. 같은 순위면 비율 게이트가 정한 결손 유형 우선
   - **연예인 슬롯은 주제가 아니라 첫장 이미지로 채운다 (비율 표의 "연예인 무관 주제 + 연예인 이미지 첫장 25%").** 재테크·정보 소재도 장면 맞는 연예인 이미지를 표지에 얹으면 연예인 슬롯이다. "연예인 소재가 없어서 못 채운다"는 판정은 오독이다
2. **소재는 제목이 아니라 원석이다 (2026-09-06 사용자 확정).** 받은 제목을 그대로 검색해서 "이미 있네" 하고 폐기하는 짓 금지 — 남의 제목이니 원본이 나오는 건 당연하다. 순서: ① 소재에서 핵심 팩트·재미 포인트만 꺼낸다 ② **우리 각도·우리 제목으로 가공한다** ③ 그 가공본 기준으로 검증한다. 검색은 팩트 확인 + "팔로워가 '또야' 할 만큼 도배됐나" 확인용이지, 존재 확인용이 아니다
3. 검증은 이 스킬의 게이트 그대로: 팩트 게이트(숫자·인물·시점 확인, 틀리면 탈락) · 리스크 게이트(비방·의료·정치) · 흔함은 아래 "흔함 킬 체크"의 2026-09-06 개정 기준("헐 몰랐다"면 통과)
4. 통과 → `주제풀.txt`에 적고(출처: `노션` + 원출처) DB `상태=사용`. 이후 대본작성 스킬부터 기존 파이프라인 그대로
5. 탈락 → DB `상태=폐기` + `검증메모`에 사유 한 줄. 다음 순위 후보로 넘어간다. 전부 탈락하면 0건 종료 보고 (서치로 넘어가지 않는다)

## 제0원칙 — 주제가 전부다

**주제가 안 좋으면 하나마나다.** 대본·카드·캡션이 아무리 좋아도 주제가 약하면 조회수는 안 나온다.
- 애매하면 통과시키지 않는다. "그럭저럭 괜찮은데?"는 탈락이다
- 할당량을 채우려고 약한 주제를 넣지 않는다. 10건 목표에 확신 있는 게 6건뿐이면 6건만 넘기고 발굴을 더 한다
- 시간 배분도 여기에 제일 많이 쓴다. 발굴을 대충 하고 제작을 열심히 하는 건 순서가 거꾸로다

## 비율 — 사용자 확정 (2026-09-01)

| 유형 | 비중 |
|---|---|
| 연예인 주제 + 연예인 이미지 첫장 | 25% |
| 연예인 무관 주제 + 연예인 이미지 첫장 | 25% |
| 정보 | 25% |
| 순수재미 (테스트·공감·습관·게임 모음 등, 연예인 이미지 없이) | 10% |
| 제철 시리즈 (계절·명절·다가오는 날짜) | 10% |

**비율 게이트 (2026-09-02 확정 — 이거 없으면 발굴 진행 금지):**
- 참고자료/·스타일 도감을 본 다음, 주제 수집을 시작하기 전에 `발행대장.txt`의 **최근 발행분 유형 비율을 세어 위 표와 비교한 결과를 한 줄로 먼저 적는다.** 예) "최근 10건: 연예인 2 / 정보 5 / 재미 3 → 정보 과다, 이번 회차는 연예인·제철 우선"
- 이 확인 줄 없이 수집한 발굴은 무효다. 주제풀 기록·대본작성으로 못 넘어간다
- 이번 회차에 뽑을 유형은 이 비교 결과가 정한다. 표의 퍼센트에 모자란 유형부터 채운다

- 핵심: **첫장에 연예인 이미지가 들어가는 게 절반.** 이미지가 유입을 만들고, 주제는 연예인과 무관해도 된다 (장면·분위기만 맞으면)
- 정보도 저장형 원칙 유지 — "이걸 저장하나?" 판별 질문 그대로
- **잡학 상식은 0에 수렴** — "이거 몰랐네"로 읽고 끝나는 지식(저장 안 하는 정보)은 사실상 안 한다
- 판별 질문: **"이걸 저장하나?"** 저장할 이유(나중에 꺼내 씀 / 내 경우 찾아봄)가 없으면 탈락
- **저장 판별은 정보 축에만 적용한다 (2026-09-06).** 순수재미·연예인 축의 기준은 저장이 아니라 **공유·태그 유발**("친구 태그하고 싶나")이다. 재미 소재에 "저장 이유 없음"을 들이대지 마라
- 저장형 꿀팁의 신박함 = **각도**다. 남이 정리한 팩트라도 우리 각도·연출이 새로우면 통과 (아래 흔함 킬 체크의 2026-09-06 개정 기준과 같음)
- **그냥 재미는 부족하다. 신박해야 한다.** 어디서 본 듯한 유머, 뻔한 공감(월요일 싫어 류), 지금 피드마다 도는 밈 재탕은 탈락. 처음 보는 각도, 예상 못 한 조합이면 통과
- 신박함 판정 질문도 하나로 통일 (2026-09-06): 팔로워가 **"헐 몰랐다"냐 "이거 또야"냐.** "이미 존재하냐"로 판정하지 마라

## 흔함 킬 체크 (2026-09-02 신설 — AI 습성 방지. 2026-09-02 선크림세안 사고에서 나옴)

**AI 습성:** AI는 서치를 많이 한 뒤 후보가 하나만 남으면, 빈손으로 회차를 끝내는 걸 실패로 느껴서 그 후보를 통과시키는 쪽으로 스스로를 설득한다. 기준을 몰라서가 아니라 결과물을 내고 싶어서 기준을 안 들이대는 것이다. 이 습성이 "애매하면 탈락"을 무너뜨린다.

**강제 절차 — 주제풀에 적기 전에 후보마다:**
1. 통과 근거 말고 **탈락 증거부터 검색한다.** "[주제] 정리", "[주제] 꿀팁", "[주제] 카드뉴스"로 검색
2. **흔함의 기준 (2026-09-06 사용자 2차 정정 — "존재 여부"는 기준이 아니다):**
   - **기사·정리글·남의 카드가 존재한다 = 탈락 아니다.** 벤치마킹 계정들도 전부 기사·남의 소재로 만든다. 세상에 아무도 안 다룬 주제는 없다
   - 판단 질문은 딱 하나: **"우리 팔로워가 보면 '헐 몰랐다'냐, '이거 또야'냐.** 후자만 탈락
   - '이거 또야'의 실례: 민생지원금·근로장려금(뉴스 도배로 다 앎), 월요일 싫어(뻔한 공감), 지금 피드마다 도는 밈 재탕
   - '헐 몰랐다'면 기사 몇 건·나무위키 등재·남의 카드 존재해도 통과. 각도·연출로 차별화하면 된다
3. **검색은 짧게 (2026-09-06 사용자 확정 — 토큰 절약).** 후보당 킬 체크 검색은 1~2회로 끝낸다. 도배 증거("이거 또야"급)가 바로 안 보이면 **바로 통과**, 보이면 그때만 더 판다. 디테일 검색으로 후보 하나에 토큰 태우지 마라
4. 이 킬 체크 검색 결과를 주제풀 항목에 한 줄로 기록한다. **기록 없는 후보는 통과 무효**

후보가 전멸해도 기준을 낮추지 않는다. 아래 "막히면 루프"로 **좋은 후보가 나올 때까지 서치한다.** 뭐라도 넘기려고 기준을 낮추는 순간이 사고다.

## 막히면 루프 (2026-09-02 사용자 확정 — 서치해도 안 나올 때의 강제 절차)

발굴처를 돌았는데 통과 후보가 안 나오면, 애매한 걸 올려보내지 말고 이 루프를 돈다:

1. **멈추고 제목 예시 목록을 읽는다** — 대본작성 스킬 3-0-1의 사용자 확인본 수십 개. (참고자료/는 방 시작에 이미 봤으니 다시 안 본다)
2. **읽었다는 기록이 없으면 재서치 진행 금지.** 예시에서 떠오른 아이디어(검색 방향) 2~3개를 한 줄로 적어야 다음 단계로 간다. 예) "내부자 프레임(다이소 직원들만~) + 시의성(내일 당장 스벅~) 결로 재서치"
3. **떠오른 아이디어를 검색어로 바꿔서 발굴처·웹검색을 다시 돌린다.** 아이디어는 검색을 다시 시키는 용도일 뿐, 아이디어 자체를 주제풀에 넣는 건 금지다
4. 재서치에서 실제 글·조회수·근거가 잡힌 것만 후보가 된다. 검색에서 안 잡히면 그 아이디어는 버린다
5. 아이디어가 떨어지면 1번으로 돌아가 예시를 다시 본다
   - **상한 3회전 (2026-09-06 개정 — 하루 4방 연속 전멸·토큰 낭비 사고에서 나옴).** 3회전을 다 돌고도 통과가 없으면 기준을 낮추지 말고 **0건 종료로 보고하고 끝낸다.** 무한 루프 금지
6. 좋은 후보의 기준은 이미 다 있다 — 이 스킬의 검증 기준 + 참고자료/ 실물 + 제목 예시 43개. 자료가 없어서 못 찾는 게 아니다. 못 찾고 있으면 서치가 얕은 것이니 발굴처를 더 깊게(랭킹 다음 페이지, 다른 게시판, 다른 검색어) 판다

## 소재 축 5개 (2026-09 계정 11곳 분석으로 확정)

1. **저장형 꿀팁 (주력)** — 특정 상황에 언젠가 필요한 실용 정보. ~별 세분화 / 총정리 / ~하는 법 / 모음
2. **신박한 재미** — 공감·유머·테스트·논쟁
3. **무명 지갑 정보** — 모르는 지원금 / 안 하면 손해. 유명한 건 탈락
4. **일정·시의성** — 다가오는 날짜(축제·세일·출시·연휴·마감·운세·계절)
5. **신박한 돈 썰** — 이색 직업·의외의 수입 등. 뉴스 보도로 검증되는 것만

## 금지선 (조회수가 나와도 안 한다)

- 실명 사생활 카더라·비방 썰 (리스크 게이트)
- 하지 않은 말 따옴표 인용 (사기성)
- **언론사·기자가 찍은 사진**, 방송 캡처, 영화 장면, 캐릭터 이미지 (저작권 청구 실제로 옴)
- 정치인 소재·사진

## 연예인 이미지 규칙 (2026-09 확정)

- **연예인 본인 인스타(공개 계정)에 올라온 사진은 캡처 사용 가능 + @계정 출처 표기** (2026-09-06 사용자 승인 — 카드제작 스킬과 동일. 기자들도 쓰는 관행)
- 소속사가 문제 삼지 않는 영역
- 단, 소재는 비방·카더라 금지 그대로. 미담·공식 발표·본인 게시물 기반만
- 재미 주제도 리스크 게이트는 그대로 — 특정인 비방, 젠더·정치 대립 조장으로 흐르면 탈락. 공감과 웃음까지만.

## 0. 시작하면 먼저 읽는다 (중복 방지)

상태 확인 3종(발행대장.txt · 주제풀.txt · 제작/ 폴더 이름)은 → 지침 스킬 3절(방 시작 루틴)을 보고 해라.
이 셋과 같거나 비슷한 주제는 수집 단계에서 바로 버린다.

## 2. AI 소재 (매 회차 1~2건)

사이트 발굴과 별도로 AI가 직접 소재를 제안한다.

- 사람들이 혹할 만한 것. 난이도는 초급~중급까지만, 고급 패스
- 뻔하거나 다들 아는 내용은 스스로 탈락시킨다
- 검증(1차·2차·3차)은 다른 후보와 똑같이 통과해야 한다
- 주제풀에 적을 때 출처 자리에 `AI제안`이라고 쓴다 (단, 팩트가 필요한 소재면 실제 출처 링크를 찾아서 같이 적는다)

## 3. 1차 게이트 — 하나라도 걸리면 탈락

| | 탈락 조건 |
|---|---|
| 중복 | 발행대장·주제풀·제작 폴더에 같거나 비슷한 게 있음 |
| 이미지 | 사진 없이는 카드가 안 나옴 |
| 팩트 | 출처를 못 댐. 카더라뿐. **팩트체크가 필요한 사항은 무조건 확인하고, 확인 안 되면 폐기.** 블로그·커뮤니티는 단서로만 쓰고 출처는 공식·언론만 인정 |
| 리스크 | 정치·종교·젠더 대립 / 특정인 비방 / 의료·법률·투자 **조언** — 금지는 조언(사라·팔아라·이거 드세요 식 판단 권유)뿐이다. **제도·규정·숫자 팩트는 조언이 아니라 정보다** (예: 혼인신고 시 달라지는 제도, 해외직구 세금 기준, 규정 변경). 무명 지갑 축의 주력이니 리스크로 쓸어버리지 마라 (2026-09-06 — 재테크 45건 오폐기 사고) |
| 분량 | 카드 3~8장으로 안 떨어짐 (심리테스트만 3~12장) |

## 4. 발굴 근거 — 둘 중 하나는 반드시 있어야 한다

- **조회수**: 최근 3일 조회수 최상위 → 숫자를 적는다
- **모름**: 사람들이 잘 모르는 내용 → 이유를 적는다

조회수를 못 받은 주제는 "모름" 쪽 이유를 댈 수 있어야만 통과한다.
조회수도 없고 이유도 없으면 탈락. 빈칸 통과는 없다.

## 5. 2차 점수 — 각 0~2점, 합계 5점 이상만 통과

저장 이유 / 공유 이유 / 첫 장 후킹 / 유통기한

## 6. 3차 카테고리 조건

| 카테고리 | 조건 |
|---|---|
| 반전상식 | 출처 2개 이상 |
| 현실기준 | 기준이 3구간 이상 |
| 심리테스트 | 결과 유형 4개 이상 |
| 혜택 | 마감일이 아직 안 지남 + 공식 출처 + **무명일 것** — 민생지원금처럼 다 아는 유명한 건 탈락. 사람들이 모르는 지원금을 후킹 문구로 꼬셔서 들어오게 하는 게 원칙 |
| 랭킹 | 항목 5개 이상 |

## 7. 기록

- 통과한 것만 `주제풀.txt`에 적는다. **탈락은 적지 않는다.**
- 한 건당 3줄:

```
날짜 [카테고리] 제목
  조회수: 숫자 (또는) 모름: 이유
  출처: 링크 (여러 개면 쉼표로. AI제안이면 AI제안이라 쓰고 팩트 출처 있으면 링크도)
```
