# 카드제작

**시작 전 관문: `.claude/skills/지침/SKILL.md` 를 읽고 `지침확인: 한 줄` 을 적은 뒤 진행한다. 이 줄 없이 한 작업은 무효 (지침 5절).**
**HTML 카드까지만 만든다. PNG는 발행 직전(최종확인 스킬)에 뽑는다.**

## 1. 만드는 방법

- 순서 (2026-09-01 확정): **구상연출대본 받기 → 이미지부터 확보 → 사진을 눈으로 보고 문장·강조 단어·배치를 확정 → 대본.txt 갱신 → 카드 조립.** 팩트·출처는 대본작성에서 이미 잠겨 있으니 안 건드린다

## 1-1. 조립 전 관문 (2026-09-02 확정 — 통과 못 하면 조립 금지)

사진·색을 고른 순간, 조립하기 전에 완성본을 상상해서 두 질문에 답한다:
1. **인스타를 넘겨보던 사람이 멈출 만한가?** (제작자 눈 말고 스크롤하는 사람 눈으로)
2. **참고자료/ 실물 옆에 나란히 놓으면 어색하지 않은가?**

하나라도 걸리면 저작권·규격 등 다른 규칙을 다 통과했어도 그 재료를 버리고 다시 찾는다.
"규칙에 안 걸린다 = 통과"가 아니다. 최종 판정은 보는 사람 눈이다.

- **이미 글자가 박힌 포스터·광고물 위에 제목 얹기 무조건 금지** (2026-09-01 올영세일 표지 사고: 공식 세일 포스터 위에 제목을 얹어 글자 위 글자 = 전단지꼴. 광고물은 그 자체가 완성본이라 배경이 될 수 없다)
- 미감 사고가 날 때마다 이 절에 금지 문장 한 줄 + 사고 내용을 추가한다. 같은 걸 두 번 틀리지 않는 게 이 관문의 목적이다
- 템플릿 파일 없음. **카드생성.py의 부품 + 스타일 도감(4-3)이 곧 템플릿이다**
- 고정된 건 표지(1장) 레이아웃뿐. 나머지는 스타일 도감 보고 주제에 맞게 조립

## 2. 카드 규격

- 1080 x 1350
- 여백: 상 90 / 좌우 80 / 하 100
- 제목 글자수 → 10자 이하 132px / 11~20자 104px / 21자 이상 84px (추측값. 실측 전까지 유지)

## 2-1. 색·하단 (2026-09-01 확정)

- 테마는 **soft**(크림 바탕 + 진회색 글자 + 주황 포인트 하나)를 기본으로 쓴다. 진한 남색(rank) 같은 어두운 단색 바탕은 올드해서 안 쓴다
- **하단 꼬리(@계정명·페이지 번호) 안 넣는다** — 카드셋.json에 `"꼬리": false`. 계정명 정해지면 그때 다시 논의
- **카드에 출처 표기 안 한다.** 출처는 대본.txt와 캡션에만 남긴다

## 2-1-1. 색 로테이션 (2026-09-02 사용자 확정)

- 강조색 팔레트 예시: **연녹 · 연보라 · 연빨강 · 노랑 · 하늘.** 이건 예시일 뿐이고, 겹치지 않으면서 주제와 어울리는 색을 AI가 추천해서 써도 된다
- **직전 발행 2세트가 쓴 강조색은 금지.** 판단은 txt가 아니라 **직전 세트들의 카드 이미지·카드셋.json을 직접 보고** 한다
- **표지 배지색(주황 고정 금지)도 같이 로테이션.** 세트마다 강조색과 어울리는 배지색을 새로 고른다. 주황을 연속으로 쓰지 않는다
- 위반 사례 (이 규칙이 생긴 이유): 2026-09-02 빅뱅(노랑)→청약(또 노랑) 연속 사용

**결론 (2026-09-02 사용자 확정 — 색 정할 때 이 네 줄대로 한다):**
1. 직전 발행 2세트(전 단계·전전 단계)의 완성본을 직접 보고
2. 거기 쓴 색과 겹치지 않게
3. 지금 만드는 카드뉴스 주제와 어울리는 색을 고른다 (배지색 포함 — 배지색 = 표지 네모칸의 색)
4. 고른 색은 그 세트 안에서 표지부터 마지막 장까지 통일한다 (표지 네모칸은 노랑인데 본문 강조는 연두면 탈락)

## 2-2. 글씨체 (2026-09-01 사용자 확정 — 도현 단일)

**글씨체는 도현 하나만 쓴다. 제목·본문·말풍선·모든 장 전부 도현.** 주아·구기·송명·IBM Plex는 삭제됨 (카드생성.py에도 도현만 남김). 다른 글씨체 추가는 사용자 승인으로만.

**폰트는 로컬 파일로 심는다 (2026-09-01 확정 — 실제 사고에서 나온 것). 웹폰트에만 의존 금지.**
- 구글 폰트 링크만 걸면 로드 지연·실패 시 맑은고딕으로 대체돼 나온다. 미리보기·PNG가 그때그때 다른 글씨로 찍히는 사고가 실제로 났다
- 폰트 파일은 `작업파일/DoHyeon.ttf`. 카드생성.py가 모든 카드에 @font-face로 심는다
- 새 글씨체를 승인받아 추가하면 그 폰트도 ttf를 작업파일/에 내려받아 같은 방식으로 심는다

## 2-3. 글자 배치 (2026-09-01 확정)

- **표지(1장): 하단 기본.** 사진 + 하단 어두운 띠 + 글자 (참고자료/ 실물 기준 위치)
- **글자가 사진의 주인공을 가리면 옮겨도 된다 (2026-09-02 사용자 확정).** 특히 **연예인·셀럽 사진이면 얼굴·인물이 주인공이라 가리면 안 된다** — 이때는 글자를 위·왼쪽·오른쪽 어디로든 옮긴다 (표지 포함 모든 장). 단 텍스트 안전 사각형(아래 규칙) 안에서만. 가리는 걸 알면서 그냥 두는 게 잘못이지, 옮기는 건 자유다
- **2장부터: 위 또는 아래 자유.** 만들기 전 그 장의 내용량·리듬·사진 여백을 보고 AI가 정한다. 꿀팁형은 카드셋.json 카드마다 `"세로위치": "상"/"하"` (기본 하). 상이면 어두운 막도 위가 어둡게 뒤집힌다
- **텍스트 안전 사각형 (2026-09-02 사용자 확정):** 표지 텍스트 박스를 기준으로 상하 대칭 사각형(좌우 80 / 상 90 / 하 100 안쪽)을 잡고, **모든 장의 텍스트는 그 박스 밖으로 이탈 금지.** 네이버 클립에도 올릴 것이라 가장자리에 걸린 글자는 잘릴 수 있다. 카드생성.py가 여백을 강제하므로 커스텀 HTML을 짤 때도 이 여백을 지킨다
- 사진 카드는 만들기 전 **사진을 눈으로 먼저 보고** 여백·얼굴 위치를 확인한 뒤 배치한다. 안 보고 박지 않는다

## 3. 사진 검색어

개념을 눈에 보이는 사물·장소로 바꿔 영어 검색어 2~3개를 뽑는다.
예) "축의금" → korean wedding envelope money
세부 규칙은 없다. 상식적으로 뽑으면 된다.

## 4. 사진 고르기

**이미지는 무조건 API(Pexels·Pixabay)에서만 건지는 게 아니다.** 소재에 맞는 곳에서 가져온다:

**구글 이미지 검색을 적극 활용한다.** API만 뒤지다 어울리는 사진 없다고 폐기하지 말 것.

**표지 얼굴 규칙 (2026-09-01 확정, 2026-09-02 보강): 표지의 연예인은 본문 내용과 무관해도 된다. 순수 어그로 장치다.**
- **셀럽 표지 50% 유지 (2026-09-02 사용자 확정).** 최근 발행 10개를 **카드 이미지로 직접 보고** (txt 말고) 셀럽 표지 비율을 세서 50%에 맞춘다. **여자연예인이 조회수가 제일 잘 나와서 우선**, 남자연예인·유명 셀럽도 OK
- **각도 전환이 기본기다:** 헤어드라이기 신제품이 주제라도 표지에 드라이기·브랜드를 띄우지 않는다. 여자연예인(머리 만지는 장면)을 띄운다. **주제(대본) + 연예인(표지)을 더하는 공식**
- 표지 인물은 내용과 상관 0%여도 된다. 수면 주제에 자는 아이돌, 다이어트 주제에 빵 먹는 배우, 여행 주제에 야외 셀카 — 전부 무관 인물로 OK
- **단 사진의 "상황·분위기"는 제목과 어울려야 한다.** 인물 매칭이 아니라 장면 매칭이다 (잠 주제=눕거나 자는 포즈 / 먹는 주제=먹는 장면 / 여행=야외)
- 단일 인물 주제(○○이 입은 그 옷): 당연히 그 사람이 표지
- 고르는 기준: 제목과 어울리는 장면인가 > 얼굴이 예쁘게 나왔나 > 인물 화제성
- 사진은 본인 인스타 공개 사진 (출처 표기 불필요)

## 4-3. 스타일 도감 (2026-09-01 시작 — 규칙이 아니라 "이런 느낌"의 재현 목록. 계속 추가한다)

이 도감의 표준 예시 세트들은 **이 스킬을 만들고 다듬던 방(2026-09-01)에서 직접 제작한 실물**이다. 각 스타일엔 소재를 어떻게 찾았는지도 같이 적는다 — 스타일과 소재 발굴법이 짝이기 때문이다.

참고자료/가 곧 교본이라는 규칙은 → 지침 스킬 4절에 있으니 거기 보고 해라. 아래 도감은 그 실물에서 뽑아낸 재현 메모다.

각 스타일은 벤치마킹 계정에서 확인된 실물 느낌이다. 주제에 맞는 스타일을 골라 그 느낌대로 만든다. 셀럽 전용·제품 전용 같은 칸막이 없음 — 느낌이 맞으면 아무 주제에나 쓴다.

**고정인 것과 바꿔도 되는 것:**
- 고정 = 스타일의 **정체성 뼈대**만 (픽카드의 제품박스+설명 짝, 꿀팁형의 아이콘 제목+불릿, 이슈형의 뉴스캡처)
- **글 위치는 2장부터 자유** — AI가 사진 여백·내용량 보고 장마다 판단한다 (표지만 하단 고정)
- 변경 가능 = **이모지·아이콘·강조 색·글자색·말풍선 문구** — 전부 언제든지 바꿀 수 있다. **판단 기준은 단 하나, 미감이 맞느냐다 (2026-09-01 사용자 확정 — 제일 중요한 포인트).** 주제 분위기에 맞게 바꾼다 (피부=🧖‍♀️+연두, 돈=💰+노랑, 경고=🚨+빨강 식). 예시에 적힌 색·이모지는 그 주제에 맞았던 사례일 뿐이다
- **연습본(도감 예시)의 색을 그대로 복붙하면 탈락 (2026-09-01 확정 — 실제 사고에서 나온 것).** 세트마다 주제에 맞는 색을 새로 고른다 (붓기=물빛 하늘색 식으로 내용과 색을 연결)
- 강조색 통일 규칙은 → 2-1-1절 결론 4번을 보고 해라
- 단 한 세트 안에서는 강조 색 2개까지만, 장마다 통일
- **통일성 셀프 체크 (2026-09-01 확정): 세트 완성 전에 글씨체·강조색·말투가 전 장에서 한 몸인지 스스로 확인한다. 사용자가 지적하기 전에 잡는 게 기본이다. 아는 규칙을 절반만 적용하는 것(글씨체만 바꾸고 색은 안 바꾸는 식)이 최악이다

**스타일 1 — 픽카드** (표준 예시: 제작/2026-09-01_내돈내산템플릿/, 발행 금지 내부 연습본)
- 사진 전체배경 + 좌하단 제품컷 박스 + 브랜드 태그 + 우하단 설명. 카드셋.json 유형 "셀럽픽"
- 제품컷 박스엔 제품만 (모델 나온 홍보컷 금지 — 제품 부분만 크롭). 단독컷을 못 구하면 세트 전체를 이름 라벨로 통일
- 인물 소개, 아이템 소개, 맛집·장소 소개 등 "하나씩 보여주는" 주제 전반에 쓴다

**스타일 2 — 이슈형** (SKT 해킹 사례로 확인)
- 표지: 사건을 상징하는 이미지(로고·뉴스 장면) + 말풍선 한 줄 + 제목의 **핵심 단어만 색·형광 강조** (예: "해킹사태"=분홍, "심각한"=노랑 형광)
- 본문: **실제 뉴스 검색결과·기사 캡처를 증거로 그대로 붙인다** + 캡처 위에 드립 한 줄 ("국방부가 외출보내줌 ㄷㄷ....")
- 본문 배경은 밝은 단색(노랑 등). 시사·사건·화제 이슈 주제에 쓴다
- 캡처가 곧 팩트체크다 — 진짜 기사 화면이라 신뢰와 어그로를 동시에 잡는다

**스타일 3 — 꿀팁형** (표준 예시: 제작/2026-09-01_피부습관템플릿/, 발행 금지 내부 연습본)
- 장마다 셀럽 셀카 전체배경(주제 무관, 장면 무관도 OK — 얼굴이 곧 어그로) + 어두운 그라데이션 + 아이콘 제목 + 불릿 3개
- 불릿마다 **핵심 구절만 색 강조** (연두 #C9F227 / 노랑 #FFE14D). 카드셋.json 유형 "꿀팁", 제목·줄에 HTML 스팬 허용
- 제목 아이콘은 카드셋.json `"아이콘": "🚄"` 으로 카드마다 지정 (없으면 아이콘 없이 제목만). **표지(1장)만 레이아웃 고정, 2장부터 아이콘·이모지는 AI 미적 판단으로 자유** (2026-09-01 사용자 확정)
- 표지도 제목 단어별 색 강조 가능 (제목에 스팬 넣으면 됨)
- 관리법·습관·목록형 꿀팁 주제에 쓴다. 장수가 늘어도 되는 몇 안 되는 형식 (원본도 6장)

**연예인 사진 확보 규칙 (2026-09-01 확정 — 실제 사고에서 나온 것. 전부 지킨다):**
1. **사진 재사용 금지.** 다른 제작 세트에서 쓴 사진을 돌려쓰지 않는다. 세트마다 새로 구한다
2. **og:image 금지.** 기사 대표 이미지(og:image)는 링크 공유용 가로 썸네일(1200x630)이라 세로 카드에 못 쓴다. 반드시 **기사 본문 안의 원본 이미지**에서 세로 사진을 추출한다
3. **받은 사진은 쓰기 전에 무조건 눈으로 본다.** 구도(세로인가), 얼굴 잘림, 화질 확인. 안 보고 박지 않는다
4. **같은 인스타 게시물을 받아쓴 기사가 여러 개면 전부 같은 사진이다.** 기사 수 ≠ 사진 수. 중복 확인한다
5. **한 세트 안에서 인물 겹침 금지.** 5장이면 5명. 검색도 인물 수만큼 따로 한다
6. **인물 조합: 유명 연예인 + 지금 이슈인 연예인 + 인지도 10위권 밖(덜 알려진) 연예인을 섞는다.** 톱스타로만 채우지 않는다

**스타일 3-1 — 시의성 정보형** (표준 예시: 제작/2026-09-01_추석기차표예매/, 사용자 승인 2026-09-01 "개잘햇음")
- 꿀팁형의 정보 버전. 표지 = 소재 실물 사진(셀럽 아님, 한국 티 나는 사진이 오히려 정답) + 말풍선 배지 + 제목 색 강조 / 본문 = 사진 배경 + 아이콘 제목 + 불릿, 날짜·숫자만 색 강조
- 강조색은 소재에서 뽑는다 (기차=코레일 파랑 계열 #6FD3FF처럼 내용과 색을 연결. 세트 전 장 통일)
- 아이콘은 장마다 소재 매칭 (📱🚄🧳 식). 뉴스 팩트 기반 시의성·혜택·변경 안내 주제에 쓴다
- 소재 찾은 법: 구글 트렌드·커뮤니티 랭킹 돌다가 "코앞 날짜 + 올해부터 바뀐 것" 조합을 잡음 (추석 예매 = 예매 시작 이틀 전 + KTX·SRT 앱 통합). 날짜·방식은 언론 여러 곳 교차 확인 후 잠금
- 추가 예시: 제작/2026-09-02_청약통장전환/ (마감일형 — "장롱 속 옛날 통장, 9월 30일 지나면 못 바꿔요". 정부 K-공감+은행 공식으로 팩트 잠금, 표지는 한국 아파트 실물 사진, 마감 숫자만 색 강조)

**스타일 5 — 셀럽 미담형** (표준 예시: 제작/2026-09-01_신민아기부/, 2026-09-01 제작)
- 표지 = 본인 인스타 감성 사진(노을·여행 등 잔잔한 장면) + 말풍선 + 제목 한 단어만 색 강조 / 본문 = 본인 사진 배경 + 하트 계열 아이콘 + 불릿 (숫자 카드 하나 + 맥락 카드 하나면 충분, 기본 3장)
- 강조색은 **표지 사진에서 뽑는다** (노을 사진 = 골드 #FFD98A 식). 어그로가 아니라 따뜻함이 정체성이라 색도 순한 톤
- 소재 찾은 법: 구글 트렌드 급상승 인물 → **왜 떴는지 언론 기사로 확인** → 미담·공식 발표면 통과 (카더라·사생활이면 그 자리에서 폐기)
- 사진 찾은 법: 본인 인스타 사진을 실어준 기사(뉴스1 [N샷]류)의 **본문 원본 이미지**에서 세로판 추출. 기자·통신사 촬영 사진(뉴시스 등)은 걸러냄

**스타일 7 — 셀럽 이슈 3장형** (표준 예시: 제작/2026-09-02_빅뱅역주행/ · 제작/2026-09-02_효리수데뷔/, 2026-09-02 제작)
- 구조 = 표지(본인 인스타 사진 + 말풍선 + 궁금증 제목) → 2장 "지금 벌어지는 일"(숫자 팩트 불릿) → 3장 "이유"(맥락 불릿). 3장으로 끝, 맺음 없음
- 미담형(스타일 5)의 어그로·재미 버전. 소재 = 차트 역주행, 의외의 데뷔, 컴백 사건 등 **언론 팩트가 있는 연예 이슈** (카더라 금지 그대로)
- 제목 결: "지금 멜론 탑100에 【20년 전 노래】가 있음 ㄷㄷ" / "유튜브에서 놀다가 【진짜 데뷔】해버린 그룹이 있음 ㄷㄷ" — 숫자·반전을 색 강조
- **사진 소싱 (2026-09-02 발견, 제일 빠른 길): `instagram.com/{계정명}/embed` 를 브라우저로 열면 로그인 없이 본인 인스타 공개 사진의 세로 고화질 원본(cdninstagram URL)이 잡힌다.** 기사 우회보다 빠르고 화질 좋음. 받은 뒤 눈으로 보고 고르는 규칙은 그대로
- 강조색은 표지 사진에서 뽑는다 (콘서트 응원봉=노랑, 데님 청청=하늘 식). 글자 없는 티저·포스터·앨범 홍보물은 표지 금지, 본문 배경(어두운 막 아래)으로는 가능

**스타일 6 — 올영 랭킹형** (표준 예시: 제작/2026-09-02_올영립랭킹/, 사용자 승인 2026-09-02 "잘만들엇다")
- 표지 = 1위 제품의 **강렬한 발색·사용 클로즈업**(립이면 입술만, 코부터 아래) + 제목 "○○ 랭킹, 지금 1위가 의외임" 류 궁금증 후킹 / 본문 = 5위→2위 셀럽픽 레이아웃(발색컷 배경 + 제품 단독컷 박스 + 순위·한줄·가격) / **1위는 마지막 장** (2위 끝에 "그리고 1위는… →")
- 데이터 = **올리브영 공식 랭킹 페이지**(getBestList.do)에서 당일 카테고리 랭킹을 긁어 해당 품목만 추림. 날짜를 대본·캡션에 박는다 (시의성 데이터라 재탕 불가 = 킬체크 자동 통과 결)
- **이미지 = 올영 상품 상세페이지가 브랜드 발색컷 창고다.** 립 스와치·입술 클로즈업·팩샷 전부 브랜드 공식 이미지라 저작권 안전 (샤오홍슈 퍼오기 불필요). 갤러리 썸네일은 `thumbnails/550/10/...` 원본, 상세 본문은 `uploads/images/item/...`
- 제품 박스엔 **제품 단독컷만** — 모델 얼굴·글자 박힌 홍보 썸네일이면 제품 부분만 크롭
- 인스타 립 계정들 문법: 입술 클로즈업 + 한 줄 후킹("올영 직원 추천 1위", "아이돌이 극찬한"). 위아래 검은 띠 + 텍스트는 샤오홍슈 퍼온 티라 금지
- 뷰티 외에도 같은 공식 적용 가능 (편의점 신상 랭킹, 다이소 랭킹 등 "당일 공식 랭킹 + 실물컷" 조합)

**스타일 4 — 표지 팝 텍스트** (벤치마킹 붓기 계정에서 확인, 2026-09-01 등록)
- 표지 제목을 **아주 두껍게 + 흰 외곽선(테두리)** 으로 띄운다. 글자 자체가 스티커처럼 보이는 게 정체성
- 색 글자(주제색) + 두꺼운 흰 테두리 조합. 사진 위에서도 안 묻힌다
- 카드셋.json 표지 카드에 `"외곽선": true`
- 꿀팁형(스타일 3) 표지와 잘 붙는다. 연성·뷰티·꿀팁 소재에 특히

**순서 규칙 (2026-09-01 확정): 제품·브랜드가 주인공인 주제는 구글 이미지를 제일 먼저 찾는다.**
예) 위스키 브랜드별 정리, 맥주 조합, 유튜브 프리미엄 출시, 편의점 신상 — 실제 제품 사진이 표지에 보여야 클릭한다. Pexels·Pixabay는 이런 주제엔 제품이 안 나와서 뒤로.
일반 소재(청소, 잠, 돈 습관 등 제품 없는 주제)만 API 먼저.

| 소재 | 이미지 출처 |
|---|---|
| 연예인 | 본인 인스타 공개 사진 — 구글 이미지에서 찾기 (출처 표기 불필요) |
| 브랜드 신상·이벤트·세일 | 브랜드 공식 인스타·홍보 이미지·제품컷·매장 사진 사용 가능 (홍보물이라 브랜드가 환영) |
| 일반 소재 | Pexels·Pixabay API → 없으면 구글 이미지에서 탐색 |
| 실물·화면이 필요한 것 | 직접 만든 표·예시 상자·SVG로 대체 |

금지는 그대로: 언론사·기자 사진, 방송 캡처, 영화·캐릭터 이미지.

## 4-1. 한국 느낌 아닌 사진 — 원천 차단 (경우의 수)

외국 티 = 외국 간판·외국 글자·서양 건물·외국 차량·이국적 풍경 등 한눈에 "여기 한국 아니네" 싶은 요소.

| 경우 | 판정 |
|---|---|
| 사물·음식·자연·손·뒷모습 클로즈업 (국적 자체가 안 드러남) | ○ 사용 |
| 외국 요소가 있지만 작거나 배경이라 티 안 남 | ○ 사용 |
| 본문 사진 카드 — 어두운 막 0.90에 가려져 티 안 남 | ○ 사용 |
| 외국 간판·글자·건물이 또렷하게 보임 | ✗ 탈락 |
| **표지** — 표지는 밝아서 못 숨김. 외국 티가 조금이라도 보이면 | ✗ 탈락. 국적 안 드러나는 구도(사물·손·클로즈업)로 다시 찾기 |

- 표지는 "흐리게 처리해서 숨기기" 금지 — 흐린 표지 자체가 금지라서. 숨겨야 할 사진이면 다른 사진을 찾는다.
- 다시 찾아도 없으면: 사물 클로즈업으로 방향 전환 → 그래도 없으면 폐기.

1. Pexels에서 세로 사진 후보 5장
2. 없거나 부족하면 Pixabay에서 5장 더 (API 키: `작업파일/pixabay_key.txt`)
3. 고르는 기준
   - 1080 x 1350을 채울 크기
   - 주제와 직접 관련
   - 글자 올릴 빈 공간이 있음
4. 둘 다 뒤져도 맞는 사진이 없으면 → **그 주제 폐기.** 제작 폴더를 `제작/폐기/`로 옮기고 `오류기록.txt`에 한 줄

## 5. 배경 처리 (2026-09 확정)

- **표지(1장)는 무조건 사진.** AI 생성 이미지는 안 쓴다 (보류 결정), 진짜 사진만
- **표지는 어두운 막 금지** — 사진 전체를 어둡게 덮는 처리를 안 한다는 뜻. 사진 자체의 밝기는 상관없다 (선명하기만 하면 됨). 글자는 하단 어두운 띠(그라데이션) 위에 흰색으로 — 이 띠는 유지
- 표지 외 사진 카드(강조 등)는 기존 방식: 어두운 막 0.90 + 흰 글자

## 6. 저장
